# llm-as-judge
Demo em Python (Streamlit) de Eval com LLM-as-a-Judge: um atendente de IA responde a um cliente de call center e um segundo modelo, o juiz, confere em tempo real se cada regra de negocio foi cumprida, gerando nota e veredito auditaveis. Ideal para entender avaliacao automatica de LLMs na pratica
